# My_first_hackathon_agent
Kisan Dost 🌾 — An AI-powered agricultural assistant that helps Pakistani farmers with crop selection, fertilizer planning, pest &amp; disease guidance, irrigation, mandi prices, profit estimation, and government support.


Kisan Dost — Farmer's Friend

**Kisan Dost** is an AI-powered agricultural assistant designed to help Pakistani farmers make better farming decisions through simple, practical, and conversational guidance.

The system uses specialized AI agents and agricultural tools to assist farmers with different farming-related needs.

 What Kisan Dost Can Do

Crop Selection — Recommend suitable crops based on district, season, soil type, water availability, and land size.
Fertilizer Planning — Help farmers estimate fertilizer requirements for their crops and land.
Pest & Disease Guidance — Provide general guidance for identifying and managing crop pests and diseases.
Weather & Irrigation — Help with irrigation and weather-based farming decisions.
Mandi Prices — Assist with agricultural market and crop price information.
Profit Estimation — Estimate potential farming costs, yield, revenue, and profit.
Government Support — Help farmers discover relevant agricultural subsidies, loans, and government support.
Safety Guardrails — Includes input and output safety checks, including pesticide-safety protections.
Simple Urdu-English — Designed to communicate with farmers using simple Urdu-English / Roman Urdu.

 Agent Architecture

Kisan Dost uses a multi-agent architecture where a main **Kisan Dost Agent** routes farming questions to specialized agents:

Agronomy Agent
Pest Agent
Market Agent
Finance Agent

These agents use dedicated agricultural tools to provide more focused responses.
